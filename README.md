# WiNNoW

> 폴더에 사진을 넣으면, 비슷한 컷을 묶어 잘 나온 걸 추리고 못 나온 건 버릴 후보로 분류해주는 **무료·오프라인 개인용 사진 컬링 도구**.
>
> *표기(워드마크)는 `WiNNoW`, 레포·명령어·경로는 소문자 `winnow`. 이 레포 이름은 `winnow-claude`.*
>
> 이 README는 이 프로젝트의 **마스터 플랜**을 겸한다 — 단 하나뿐인 기록이다.
> 새 채팅/새 작업은 이 문서를 읽고 시작하고, 끝에 갱신한다.
> 칸마다 `[정적]` / `[살아있음]` 표시가 있다. 바쁘면 `[살아있음]` 칸만 챙겨도 된다.
> 연속성의 핵심은 **결정 로그**와 **남은 일** 두 칸.

---

## 1. 개요  `[정적]`

- **한 줄 목표:** 폴더에 사진을 넣으면 비슷한 컷을 묶어 잘 나온 걸 추리고 못 나온 건 버릴 후보로 분류.
- **현재 상태:** 기획 완료, 구현 전 (Claude Code로 구현 예정)
- **이름 유래:** winnow = 알곡과 쭉정이를 가려내다.

## 2. 배경·조사  `[정적]`

- 비슷한 게 있나? — 있다. Aftershoot, Narrative Select, FilterPixel, Imagen 등 유료 AI 컬링 도구. 비슷한 컷 묶기·흐림/눈감음/중복 골라내기·베스트 추천을 함.
- 그걸로 충분치 않은 이유 — 전부 웨딩·행사 사진작가용(한 번에 수천~수만 장)이고, 월 $15~19 구독제. 개인이 폰 사진 정리하는 용도엔 규모도 가격도 과함.
- 그래도 만들 가치 — 무료·오프라인 개인 도구가 필요하고, **AI를 직접 다뤄보는 연습 프로젝트**로 삼을 수 있음. 나중에 더 큰 시스템(Marstell)에 모듈로 통합 가능.

## 4. 설계  `[정적 → 바뀌면 갱신]`

**동작 순서**
1. 폴더 안 사진을 다 읽고 촬영 시각(EXIF) 확인
2. 시각으로 크게 묶고, 나뉜 묶음끼리 유사도로 비교해 닮은 건 다시 합침
3. 사진마다 선명도 점수 — 격자로 쪼개 가장 선명한 칸의 라플라시안 값
4. 각 묶음에서 점수 순 정렬 → 상위 "장수 ÷ 3, 올림"만큼 keep, 흐림 경계 아래는 reject. 단 흐려도 얼굴·순간이 담겼으면 **애매**로
5. 원본은 그대로 두고 `keep` / `reject` / `애매` 폴더에 복사만

**파일 구조 (몸통 / 껍데기)**
```
winnow-claude/
├─ README.md          # 이 문서 (마스터 플랜 = 레포의 얼굴)
├─ CLAUDE.md          # Claude Code 작업 지침
├─ winnow.py          # 몸통: cull(폴더) 함수. 분류 로직 전부
├─ app.py             # tkinter 창. winnow.py를 불러다 씀
├─ requirements.txt   # 필요한 라이브러리 목록
└─ .gitignore         # 테스트 사진·결과 폴더는 git에 안 올림
```
- 핵심은 `cull(폴더) → {keep, reject, 애매}` 함수 하나(`winnow.py`). 실행 방식(터미널·창·exe)은 이 함수를 부르는 껍데기일 뿐, 함수는 안 바뀜.

**UI (tkinter, `app.py`)**
- [폴더 선택] 버튼 → 고른 폴더와 그 안 사진 장수 표시
- [실행] 버튼 → 자동 분류 시작, 진행 상황을 글 + 프로그레스 바로 표시
- 진행 문구 예: 불러오는 중 → 비슷한 사진끼리 묶는 중 → 묶음끼리 다시 합치는 중 → 잘 나온 사진 골라내는 중 → 폴더로 옮기는 중 → 끝(keep/reject/애매 장수)
- ※ 진행을 실시간으로 보이려면 분류를 백그라운드에서 돌려 창이 안 멈추게 해야 함
- ※ 하루 100~400장을 처리하므로 프로그레스 바가 특히 필요

**스택 / 라이브러리**
- 파이썬 + Pillow·OpenCV(사진·흐림), imagehash(유사도), tkinter(UI). 전부 무료·오프라인.
- v2에서 CLIP 같은 로컬 모델 추가 (exe가 커지고 포장이 까다로워지는 점 유의)

**조절할 설정값 세 개** (코드 맨 위에 모음)
- keep 비율 — 기본 3 (몇 장당 1장). 후하게 남기려면 2.5나 2
- 유사도 경계 — 얼마나 닮아야 같은 묶음으로 합칠지
- 흐림 경계 — 선명도 몇 아래면 reject/애매로
- ※ 미리 못 맞춤. 상식값 넣고 실제 사진으로 돌려보며 조절

## 7. 완료 기준  `[정적]`

> "여기까지면 끝." 완벽 말고 **충분함**으로.

- **v1:** 내 사진 폴더를 넣었을 때, 명백한 초점 실패작이 reject로 잘 빠지고, 흐리지만 볼 만한 건 애매로 남는다. 내가 쓰기에 충분하면 완성.
- **v2:** 내가 고르던 것과 비슷하게 순위를 매겨준다. 취향 100% 재현은 목표가 아님 — "버리기 전에 볼 가치가 있는 걸 놓치지 않는다"가 목표.
